# 小学社群运营 · 过程数据分析平台

## 业务背景

社群运营每周一期进行续报，但手上只有一堆过程数据（到课率、app下载……），复盘靠的是大家主观感觉：这期到底哪弱了？下期该补哪块？和同组其他人比差在哪？

这个平台就是为了解决这件事——把每期的过程数据变成一个能复盘、能诊断、能预测的闭环，让运营从"凭感觉"变成"看数据补短板"：这期 vs 上期哪退步了、同期同组我排第几、下期该发力哪个环节，一打开就有答案。

> 定位：一个业务理解 + 数据驱动 + 自驱落地的作品。我作为业务 owner 把分析逻辑设计出来，底层代码由 AI 编程工具生成。

---

## 我的角色

我是这个项目的业务 owner，不是写全部代码的工程师：

定指标：把转化拆成七环漏斗（好友率 → 入群率 → APP 下载率 → 开营回复率 → Day1 到课率 → Day3 出直播间转化率 → 最终转化率），每环可量化
设计复盘 / 诊断逻辑：环比（这期 vs 上期）看趋势、同期同组对比看团队位置、个人转化预测用近邻法按真实漏斗口径出值
定验收标准 + 测 bug：哪些结果算对、哪些口径会出错，由我来跑测 bug
代码虽然不是我手写的，但分析框架、指标口径、业务取舍是我想透并定义的——我认为这恰恰是一个销售运营岗最该有的能力：懂业务、能把模糊的业绩变成可盯可拆可改的指标。

## 功能模块

| 模块 | 业务价值 |
|---|---|
| 个人环比复盘 | 每期自动对比本人上一期，弱项指标标红，直接指出下期发力点 |
| 团队复盘 | 看团队整体过程数据走势 |
| 个人诊断 | 同期同组对比，看清自己在团队里的位置 |
| 转化率预测 | 个人历史近邻法（KNN）预测 Day3 / 最终转化率；严格按真实漏斗口径（Day3 ≤ 最终），不反号 |
| AI 复盘结论 | 接入 DeepSeek，结合团队沉淀的 SOP 方案，自动产出下期行动清单 + 延展思路 |
| 数据上传 / 查看 | 按模板批量导入，年级 / 学科唯一性校验防止多人录入串数据 |

**核心设计取舍（这些是我的业务判断，不是技术细节）**
- 复盘只做「这期 vs 上期」，**不展示整期均值**——均值对一线运营没意义，运营要看的是自己每一期的进退。
- 杠杆模型（回归）只用来给过程指标**排优先级**，不展示 p 值 / R² 等术语——业务方不需要看统计黑话。
- **识别不可控变量**（如好友率由前端 BD 引流质量决定，运营改不了），不把它列为可优化短板，避免给假行动项。
- Day3 出直播间转化率与最终续报率**同口径**、Day3 ≤ 最终，预测不乱给反号结果——口径对齐是分析不出错的前提。

---

## 可迁移性

这套"指标拆解 → 环比 / 同组对比 → 弱项行动清单"的方法论是通用的，不只适用于社群续报：

- 换到**本地生活 / 销售运营**场景，漏斗从七环换成 POI 覆盖率 → 团购购买率 → 核销率 → 动销门店数，逻辑一模一样——先对齐口径，再拆结构找真凶，最后落到动作。
- 它解决的也是同一个管理问题：**让一线团队用数据做日常追踪与复盘决策**，而不是靠经验直觉。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 AI（可选，不配也能跑，只是没有 AI 复盘结论）
#    复制 ai_config.example.json 为 ai_config.json，填入你的 DeepSeek key
cp ai_config.example.json ai_config.json
#    编辑 ai_config.json，把 deepseek_key 改成你自己的

# 3. 启动
python app.py
#    默认监听 http://127.0.0.1:5000

# 4.（可选）填充演示数据，便于直接看到各模块效果
#    插入的是完全虚构的演示记录（演示甲/乙/丙…），不含任何真实业务数据
python seed_demo_data.py
```

## 数据说明

- 开源仓库**不含真实业务数据**。首次运行会生成空库，需在页面「数据上传」按模板导入。
- 导入模板表头（CSV）：
  `期次,姓名,学科,年级,好友率,入群率,APP下载率,开营回复率,Day1到课率,Day3出直播间转化率,最终转化率`
- 率字段为百分比数值（如 52 表示 52%）。
- 同名同人（同姓名 + 同学科）在库里只能有一个年级，跨年级或空年级会被拦截。

## 演示

仓库不含录屏文件（避免泄露真实数据截图）。本地预览方式：

3. 浏览器打开 http://127.0.0.1:5000 ，即可看到个人环比复盘、个人诊断、团队复盘、转化率预测等模块效果。

如需对外展示录屏，请用本地真实运行环境自行录制（建议先跑种子脚本填充数据）。
